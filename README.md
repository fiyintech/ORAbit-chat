# ORAbit — Temporary Chat

A creepy temporary-chat web app built with Next.js.

## Run locally

1. Install Node.js LTS.
2. Open a terminal in this project folder.
3. Run:

```bash
npm install
npm run dev
```

4. Open http://localhost:3000
